# 🌐 Capstone Project – Responsive Web Interface (HTML5 & CSS3)

## 📌 Project Theme
**[E-commerce]**

This project is a fully structured, responsive, and visually polished web interface designed using only **HTML5 and CSS**. It represents a real-world UI scenario using semantic structure, Flexbox/Grid layouts, responsive design, and modern styling techniques.

---

## 📝 Project Description
The objective of this project is to build a complete, responsive static website that demonstrates:
- Proper semantic HTML5 structure  
- Responsive layouts using Flexbox & CSS Grid  
- A visually appealing theme-based design  
- Forms, banners, lists, and card layouts  
- Custom styling, hover effects, and accessibility-friendly code  

The website includes:
- **Header & Navigation**
- **Hero/Banner section**
- **Multiple theme-based content sections** (e.g., cards, testimonials, pricing, filters)
- **Responsive Grid layout**
- **Contact/Inquire form**
- **Footer with links and icons**

---

## 🧩 Features Implemented

### ✔ Semantic Structure
Uses proper HTML5 elements such as:
`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.

### ✔ Responsive Layouts
- Mobile-first structure  
- Breakpoints for **mobile, tablet, and desktop**
- Flexbox used for header/footer alignment
- Grid used for cards (courses, properties, products, items, etc.)

### ✔ Visual Design
- Custom color theme & typography (Google Fonts)
- Buttons, cards, and navigation links styled consistently
- Smooth hover animations (`transition: 0.25s ease`)
- One keyframe animation (hero fade-in/slide-in)

### ✔ Form Implementation
- Contact / inquiry form with:
  - Proper labels  
  - Required fields  
  - Placeholders  
  - Accessible structure  

### ✔ Accessibility
- Alt text for all images
- Semantic structure for screen readers
- Good contrast and readable font sizes

---

## 🖥️ Breakpoints Used
| Device | Width | Behavior |
|--------|--------|----------|
| **Mobile** | ≤ 480–600px | Single-column layout, stacked header, grid becomes 1-column |
| **Tablet** | ~768px | Grid becomes 2-column, spacing adjusts |
| **Desktop** | ≥ 1024px | Full multi-column layout, expanded navigation |
