# 🌐 Responsive Portfolio Website

## 📖 Lab Title
**Lab 3: Responsive Portfolio Website using Flexbox, Grid & CSS Animations**

## 📝 Description
This project is a **one-page responsive portfolio website** built by enhancing the previous Lab 2 project.  
It uses **Flexbox**, **CSS Grid**, **media queries**, and **CSS animations** to create a modern, interactive, and fully responsive layout.

The portfolio includes the following sections:
- Header  
- Hero  
- About  
- Skills  
- Projects  
- Contact  
- Footer  

---

## ✅ Features Implemented

### **1. Flexbox Layout**
- Used for the header navigation and hero section alignment.

### **2. CSS Grid**
- Applied in the **Skills** and **Projects** sections for card-based layouts.

### **3. Responsive Design**
- Mobile-first approach.
- Media queries for mobile, tablet, and desktop screen sizes.

### **4. Relative Units Used**
- Used `rem`, `em`, `%`, `vh`, and `vw` for spacing, layout, and font scaling.

### **5. Typography**
- Integrated Google Fonts.
- Clear font hierarchy for readability.

### **6. Color Theme**
- Consistent 2–3 color scheme throughout the layout.
- Includes a color-changing animation on highlighted text (e.g., “Full Stack Developer”).

### **7. Hover Effects**
- Smooth transitions on buttons, navigation links, and project cards.

### **8. Animations**
- Keyframe animations for hero text.
- Fade-in/slide-in effects for sections.

### **9. Contact Section**
- Simple form with name, email, and message fields.

### **10. Footer**
- Includes copyright info and social links.

## 📱 Responsive Breakpoints Tested
| Device | Breakpoint | Behavior |
|--------|------------|----------|
| **Mobile** | 0–480px | Hero stacks vertically, grid becomes 1 column |
| **Tablet** | 481–768px | Grid becomes 2 columns |
| **Desktop** | 769px+ | Full multi-column layout |
